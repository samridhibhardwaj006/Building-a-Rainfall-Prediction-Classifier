# Building-a-Rainfall-Prediction-Classifier



📖 About

This notebook is a hands-on lab from the IBM AI Engineering Professional Certificate on Coursera. It walks through building a machine learning classifier to predict whether it will rain, using a real-world weather dataset — covering the full ML pipeline from raw data to evaluated model.


⏱️ Estimated time: 60 minutes




🎯 Objectives

By completing this lab, I was able to:


🔍 Explore & engineer features on a real-world dataset
🏗️ Build a classifier pipeline and optimize it using Grid Search Cross Validation
📊 Evaluate the model using performance metrics and visualizations
🔄 Swap in a different classifier by simply updating the pipeline
⚙️ Tune hyperparameters with an appropriate search space for each classifier



🧪 ML Pipeline Overview

Raw Weather Data
      ↓
Feature Engineering & Preprocessing
      ↓
Classifier Pipeline (e.g. Logistic Regression / Random Forest)
      ↓
Grid Search Cross Validation (Hyperparameter Tuning)
      ↓
Model Evaluation (Accuracy, Confusion Matrix, ROC Curve)
